# RAHSA Implementation Kits

This directory stores just-in-time execution packages for approved RAHSA implementation tasks.

Read `docs/IMPLEMENTATION_KIT.md` for the governing standard.

Each active task uses:

```text
implementation-kits/Txxx/README.md
```

with optional task-specific patch and PowerShell helper files beside it.

Implementation Kits are non-authoritative execution aids. `TASKS.md` and higher-level product/security documents remain authoritative.

Do not place credentials, keystores, signing material, real vault files, or other secrets in this directory.
